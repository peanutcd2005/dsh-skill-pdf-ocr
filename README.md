# dsh-skill-pdf-ocr

DeepSeek Harness 技能：把扫描版 PDF 或图片里的文字识别出来。

## 解决什么问题

政府公文、标准规范、扫描件的 PDF 常常没有文字层——直接抽取得到空字符串；或者文字层损坏，抽出 `犐犆犛０７．０６０` 这种生僻怪字。本技能用本地 OCR 把它转成可读文本。

典型场景：文件名里没有年份和发文机关，需要从正文首页补出来；需要确认某份文件是否已被废止。

## 依赖

| 包 | 用途 |
|---|---|
| `pypdfium2` | 把 PDF 页面渲染成图片 |
| `rapidocr-onnxruntime` | 中文 OCR 引擎 |

两者都在本地运行，文件不上传，也不必联网。模型随包安装，不需要额外下载。

## 安装

```powershell
pip install pypdfium2 rapidocr-onnxruntime
```

把本目录放到 DSH 的技能目录：

```
$DSH_HOME\skills\pdf-ocr\
    SKILL.md
    scripts\ocr_pdf.py
```

## 用法

```powershell
python scripts/ocr_pdf.py --input "某文件.pdf" --pages firstlast --out "输出.txt"
```

`--pages` 取值：

| 值 | 含义 |
|---|---|
| `firstlast` | 默认。首页 + 末页 |
| `first` | 只首页 |
| `last` | 只末页 |
| `all` | 全部页 |
| `1-3,5` | 指定页码，从 1 开始 |

`--scale` 默认 2.5（约 180 dpi），字小时可提到 3.0。

## 为什么默认只扫首末页

公文的关键信息高度集中：首页有标题、文号、发文机关、成文日期；末页有施行日期和废止条款。中间正文在整理归档时用不上。

一份 68 页的标准，全量 OCR 是 68 页，只扫首末页是 2 页，信息已经够用。

## 先判断要不要 OCR

不要无脑 OCR。先试着抽文字：

- 抽出正常中文 → 直接读，OCR 只会引入错字
- 抽不出任何文字 → 扫描件，用本技能
- 抽出乱码 → 字体编码损坏，等同扫描件

## 边界

- 中文印刷体识别效果好；手写体、印章覆盖、密排表格明显变差
- 扫描歪斜、墨色浅的页面错字增多，结果需抽查
- 首末页可能都是封面，遇到这种情况补扫第 2 页
- 不处理加密 PDF
